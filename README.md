# web check siu cấp vip pro

Công cụ rà soát đối chiếu đồng thời 3 file Chương trình Đào tạo (**File gốc MyBK**, **Bản đẹp CTĐT**, **Bản đẹp KHGD**):
- **B1:** Rà soát nhóm khối kiến thức / học kỳ & phân loại Bắt buộc `[BB]` / Tự chọn `[TC]`.
- **B2:** Rà soát môn bị sót 2 chiều, tổng tín chỉ, đối chiếu từng dòng & lỗi chính tả Anh/Việt.
- **B3:** Rà soát điều kiện tiên quyết (`TQ`, `HT`, `SH`, `KN`), điều kiện ngoại ngữ tốt nghiệp (`ENG_B2`) & chú thích.
- **B4:** Xuất bản sao `.xlsx` giữ nguyên 100% định dạng gốc kèm **tô đỏ / chữ đỏ** trực tiếp trên ô sai hoặc thiếu + khung Note riêng cho file MyBK để báo Cô.
